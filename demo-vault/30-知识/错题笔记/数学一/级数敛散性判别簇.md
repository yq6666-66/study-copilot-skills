# 级数敛散性判别簇

> 对应错题队列：`r008`（判别法选择）、`r009`（莱布尼茨漏验单调性）。**原创虚构示例**。

## 错误表现

- 通项含阶乘时仍先用比较判别法，绕远路。
- 交错级数只验证了通项趋于 0，漏验单调递减。

## 判别法选择树（自建口诀）

1. 通项含 $n!$ 或 $a^n$ → 先试比值判别法
2. 通项是 $p$ 次多项式比值 → 比较判别法（抓主项）
3. 交错级数 → 莱布尼茨：**递减 + 趋零，两验缺一不可**
4. 含 $\sin/\ln$ 混合 → 先泰勒展开看阶
