# AGENTS.md — 演示 Vault 使用说明

本目录是「学习副驾 Study Copilot」的**脱敏演示 Vault**，所有数据均为原创虚构，用于功能演示与端侧检索冒烟测试。

## 目录结构

```
demo-vault/
├── AGENTS.md            # 本文件
├── 00-系统/知识库索引.md  # 总索引
├── 20-项目/              # 学习档案、进度快照
├── 30-知识/              # 错题队列.json + 错题笔记/
└── 40-真题/真题索引.md    # 真题索引骨架（不含真实试卷数据）
```

## 给 Agent 的规则（摘要，全文见插件内 obsidian-brain-contract.md）

1. 检索优先级：`20-项目/` → `30-知识/` → `40-真题/`；先读索引摘要，再打开必要正文；单轮最多 8 篇 / 16,000 字符。
2. 写入前重读目标文件，内容变化时合并，不覆盖。
3. 计划只能写 `planned`；推测错因标 `hypothesis`，有复测证据后才标 `confirmed` / 掌握。
4. 不保存整段对话、凭据、身份信息、未授权题库或第三方解析。
5. 用户说「只读模式」时可检索禁止写入。

## 端侧检索

错题队列与笔记可由 `scripts/local_retrieval/embed_index.py` 建立本地向量索引（写入 `30-知识/.index/`，不上传）。详见插件内 local-semantic-retrieval-contract.md。
