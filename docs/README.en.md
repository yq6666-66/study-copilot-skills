# Study Copilot

> A universal learning-cognition engine for any AI agent — any host × any subject, with a ready-made postgraduate-exam (考研) subject pack.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](../LICENSE) [![CI](https://github.com/yq6666-66/study-copilot-skills/actions/workflows/ci.yml/badge.svg)](https://github.com/yq6666-66/study-copilot-skills/actions/workflows/ci.yml) [中文](../README.md)

**Study Copilot** is a pure-Skills learning engine with zero backend services. Install it into an AI agent (OpenAI Codex, Claude Code, …) and the agent gains cross-session learning memory, error-loop coaching, spaced repetition, study planning, progress diagnosis and original mock exams.

> Repo: https://github.com/yq6666-66/study-copilot-skills · Predecessor: [kaoyan-408 plugin v2.4.0](https://github.com/yq6666-66/408-codex-plugin)

This project is the generalized successor of the author's earlier exam plugin, with two layers of generalization:

1. **Any agent** — Skills are host-decoupled; an adapter layer + installer places the same pack into different hosts.
2. **Any subject** — the mechanism layer (error loop / planning / diagnosis / mock exams) treats `subject` as a free string;学科 content is driven by declarative subject packs under `subjects/` (考研 pack preloaded; new subjects generated by the onboarding wizard).

## Features

- 🔁 **Error-loop coaching**: clusters error causes across questions (confirmed vs. hypothesis strictly separated), schedules spaced retests, gates "mastered" behind observable evidence
- 📅 **Planning & execution**: goal-date back-planning into stage/month/week quotas, expanded into actionable timeboxes
- 📊 **Progress diagnosis**: from recorded data only — never fabricated
- 📝 **Original mock exams**: frozen papers, no hints before submission
- 🧠 **Local learning memory**: optional Obsidian Vault owned by the user; nothing is uploaded
- 🔍 **On-device semantic retrieval**: bge-small-zh embedding (ONNX, CPU) indexes error queues and notes locally
- ☁️ **Cloud Qwen channel**: DashScope `qwen-flash` / `qwen3.8-flash` for coaching, subject-config generation, content production, data analysis and code review — **34 real calls, every one trace-logged under `logs/qwen/`** (aggregation: `python scripts/qwen_engine.py --stats`)
- ⏱️ **FSRS spaced-repetition scheduler** (new): `scripts/scheduler.py` implements the open-source FSRS core (forgetting curve / initial stability / mean-reversion damping, citing open-spaced-repetition/fsrs-rs) — suggested review dates + today's retrievability per item
- 📈 **Weekly study report** (new): `scripts/study_report.py` builds mastery overview / error hotspots / 7-day FSRS workload; insights section generated by cloud Qwen with trace (sample: `docs/competition/学习周报示例.md`)
- 📦 **Edge-cloud synergy with graceful degradation**: either side can fail without blocking learning; a `[Qwen-generated]` label never appears without a real call behind it

## Architecture

Three layers: host adapters (`adapters/`, `install.py`) → universal Skills core (`plugins/study-copilot/`: 15 skills + 23 contracts) → subject packs (`subjects/`), with local retrieval (`scripts/local_retrieval/`) and the cloud engine (`scripts/qwen_engine.py`). Details: [ARCHITECTURE.md](ARCHITECTURE.md) — note its first draft was generated by qwen3.8-flash and manually audited (one fabricated historical claim was removed; document paths are gated in CI).

## Quick start

```bash
git clone https://github.com/yq6666-66/study-copilot-skills.git
cd study-copilot-skills

python install.py --host auto --dry-run     # detect Codex / Claude Code first
python install.py --host claude-code        # then install

python scripts/check_contract_coverage.py   # 15 skills × 23 contracts: no dead links, no orphans

# One-command edge-cloud demo (device-side recall → Qwen variant exercise → trace)
python scripts/demo_pipeline.py --item r028            # needs DASHSCOPE_API_KEY
python scripts/demo_pipeline.py --item r028 --dry-cloud # offline preview
```

## Engineering narrative (10 optimization rounds)

The project was deepened over ten rounds on 2026-09-14 by a **qwen3.8-flash-driven coding session**, each round anchored to commits, CI run IDs and call traces: vector caching → CI bootstrap (which caught two cross-platform bugs on its first run) → one-command demo pipeline + performance benchmark (which then caught *its own* JSON-cache regression and a measurement flaw — fixed with npz binary cache, 19× incremental speedup at 2,000 docs) → semgrep security gate (caught two leaked user paths in docs) → AI-generated architecture doc with hallucination removed during human audit → CLI error-message redesign reviewed by a real Qwen call (which caught a deliberately planted factual error) → Python version matrix → contract-coverage gate → changelog/README consistency.
