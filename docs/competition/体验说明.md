# 体验说明

**学习副驾 Study Copilot** —— 装进任何 AI Agent 的通用学习认知引擎（任何 Agent × 任何科目，预置考研包）。

> **运行/安装/登录方式**：① 登录——本项目**无账号体系、无需登录**，无遥测；② 安装——`python install.py --host auto` 一条命令装进 Codex 或 Claude Code（纯本地文件，卸载按清单）；③ 运行——命令行 + Agent 对话（下方 5 分钟路径），唯一可选项是云端 Qwen 能力所需的本地环境变量 `DASHSCOPE_API_KEY`（配置见后，不配置则自动降级、其余功能不受影响）。

## 环境要求

- Windows / macOS / Linux，Python 3.10+
- 任一宿主 AI Agent：Codex 或 Claude Code（其他 Agent 见 `adapters/README.md` 文档级接入）
- 可选：DashScope API Key（`setx DASHSCOPE_API_KEY "sk-..."`）——仅 Qwen 错题陪练链路需要；没有也能体验其余全部功能
- 可选：Obsidian（本地记忆 Vault 的图形化查看；不用 Obsidian 也可直接看 `demo-vault/` 目录）

## 5 分钟体验路径

```bash
# 0）进入仓库，跑一遍测试确认环境 OK（应显示 18 passed）
python -m pytest tests/ -q

# 1）端侧语义检索（AI PC 本地算力，无数据出域）
python scripts/local_retrieval/embed_index.py --fake          # 离线冒烟（不下载模型）
python scripts/local_retrieval/semantic_search.py --query "银行家算法总是算错" --fake
#   真实语义模型（首次下载约 100MB，缓存到 models/）：
#   python scripts/local_retrieval/download_model.py
#   python scripts/local_retrieval/embed_index.py && python scripts/local_retrieval/semantic_search.py --query "死锁检测漏分支"

# 2）Qwen 错题陪练（需已配置 DASHSCOPE_API_KEY）
#   最省事：一条命令跑通端云协同全链路（端侧召回→Qwen 变式题→留痕）；无 Key 时加 --dry-cloud：
python scripts/demo_pipeline.py --item r028
python scripts/qwen_engine.py --dry-run --system "你是考研陪练" --prompt "围绕错因'LRU与FIFO缺页数串页'出一道原创变式题"
python scripts/qwen_engine.py --system "你是考研陪练，只出原创题" --prompt "..."   # 真实调用，留痕在 logs/qwen/
#   无 Key 时会得到明确降级提示——这是设计行为，不是故障。

# 3）装进你的 Agent
python install.py --list                              # 看 15 个 Skill
python install.py --host claude-code --dry-run        # 预览安装计划
python install.py --host claude-code                  # 正式安装到 ~/.claude/skills/
#   Codex 用户：python install.py --host codex

# 4）在 Agent 里对话体验（示例）
#   "帮我整理 demo-vault 里 408-操作系统 的错题并安排复测"
#   → 触发 kaoyan-error-loop-coach：聚类错因 + 端侧检索相似历史错题 + ReviewQueue 排期
#   "用Qwen陪练，针对死锁这个错题簇出变式题"
#   → 触发 kaoyan-qwen-drill：变式出题 + 留痕佐证
#   "我要加法考科目"
#   → 触发 kaoyan-subject-onboarding：生成 subjects/<你的包>/profile.json
```

## 演示数据

`demo-vault/` 是脱敏演示 Vault（**全部原创虚构**）：40 条错题横跨「数学一」与「408-操作系统」两科，用于证明同一套机制跨科目工作；三个 JSON 记录均通过 Schema 1.1 校验。

## 常见问题

- **Qwen 调用返回 2（未配置 Key）**：按提示 `setx DASHSCOPE_API_KEY "sk-..."` 后**新开终端**重试。
- **端侧检索提示"未就绪"**：先 `pip install fastembed`，再跑 `download_model.py`；或继续用 `--fake` 看流程。
- **想卸载**：`python install.py --host claude-code --uninstall`（按安装清单清理，不碰学习数据）。

## 常见问题

- **安装到哪里？**  
  学习副驾安装在用户目录下的 `.claude/skills/` 或 `.codex/plugins/` 目录中。

- **没配 DASHSCOPE_API_KEY 会怎样？**  
  无 API Key 时会自动走降级路径，功能不受阻塞，但部分云端能力受限。

- **端侧模型多大、怎么下载？**  
  端侧模型约 55MB，缓存于仓库的 `models/` 目录，可通过 `scripts/local_retrieval/download_model.py` 下载。

- **怎么卸载？**  
  使用安装脚本的 `--uninstall` 参数即可完成卸载。

- **我的学习数据存在哪？**  
  所有学习数据均本地存储，不会上传至任何远程服务器。

> 本节由云端 Qwen（qwen-flash）生成，调用留痕见仓库 `logs/qwen/`。

## 隐私

学习数据全部本地存储；Qwen 调用只发送学科文本并全量留痕。详见 [PRIVACY.md](../PRIVACY.md)。
