## ① 作品介绍（≈300 字）

学习副驾 Study Copilot——装进任何 AI Agent 的通用学习认知引擎（任何 Agent × 任何科目）。

它不是又一个绑死 App 的学习工具，而是把「学习大脑」做成一套开放 Skills：一条命令装进 Codex / Claude Code 等任意 Agent，即获得跨会话学习记忆、错题闭环（错因聚类区分已确认/假设、FSRS 间隔复测排期）、学习规划、进度诊断、原创模考、考前预练能力；学科内容由科目配置包驱动，预置考研六科，法考/注会配置包已入库，新科目由向导一键接入、机制层零代码改动。

技术核心是端云协同：端侧在本地 AI PC（CPU）运行 bge-small-zh embedding，为错题库建语义索引并毫秒级召回相似历史错题，学习数据全程不出域；云端阿里云 Qwen（DashScope）承担错题陪练、变式出题、内容生成与代码评审，34 次真实调用全部留痕可交叉核验。任一端不可用即自动降级，绝不伪造生成标注。

工程质量：92 个自动化测试 × Python 3.10/3.11/3.12，六道 CI 门禁（测试/Schema/文档路径/semgrep 安全/契约覆盖/数字一致性）连续 22+ 次全绿。开源：https://github.com/yq6666-66/study-copilot-skills

赛道：赛道一「效率进化（AI WORKS）」；对齐特别赛题「基于 Qwen 大模型的认知增强」（Qwen 为运行时核心引擎，非仅开发工具）。

## ② AI 技术实践说明（表单文本框用）

**云端模型/服务**：阿里云 Qwen（DashScope OpenAI 兼容接口，qwen-flash ×28、qwen3.8-flash ×6，共 34 次真实调用，全部自动留痕于 logs/qwen/——含完整请求、回复、token 用量、时延；引擎内置断言保证日志不含 API Key，可用 `python scripts/qwen_engine.py --stats` 一键聚合复核）。

**本地端（AI PC）承担的能力**：①bge-small-zh-v1.5 embedding（ONNX，CPU 推理）为错题队列与 Vault 笔记建向量索引；②端侧语义检索召回相似历史错题（实测 60 条增量更新 0.39s、查询 p95 29ms@2000 条）；③学习记忆与数据结构化校验全部本地；④向量缓存 npz 本地存储，学习数据不出域。

**云端承担的能力**：错题陪练变式出题与二次精讲、科目配置包生成（法考/注会已入库）、原创练习/周报洞察/仪表盘摘要/Anki 卡片措辞生成、代码审查（其 4 条意见已采纳改码并附回归测试）。

**协同方式（端云串联）**：一条命令 `demo_pipeline.py`/`pre_drill.py` 即演示完整闭环——端侧召回相似错题簇 → 组织最小 prompt（仅学科文本，dry-run 隐私预览）→ 云端 Qwen 生成定向变式题 → 自动留痕回传本地记忆层。任一端不可用自动降级且明示，不伪造 `[Qwen生成]` 标注。

**AI 参与开发**：项目亦在 Qwen 模型驱动的编程会话中完成十六轮持续优化（向量缓存/增量索引/FSRS 调度/六道 CI 门禁等），提交历史与 GitHub Actions 运行记录公开可查；另有 GLM 辅助开发（如实区分，见 PRIVACY.md）。

**ZIP 内佐证（六类）**：01 Qwen 留痕×34 + 调用说明；02 端侧检索真实运行输出；03 关键代码；04 Prompt 与 Skill 设计；05 92 项测试记录；06 DashScope 平台控制台用量截图（390 请求/226.9M tokens/成功率 100%，作品链路 34 次为其真子集，口径分列）。

## ③ 运行 / 安装 / 登录方式

- **登录**：无需注册、无账号体系、无遥测。
- **安装**：`git clone` 后 `python install.py --host auto --dry-run` 预览，`python install.py --host claude-code`（或 codex）一条命令装入；卸载按安装清单 `--uninstall`。
- **运行**：①`python -m pytest tests/ -q`（92 passed）；②`python scripts/demo_pipeline.py --item r028` 一键端云协同演示（无 Key 时 `--dry-cloud` 离线预览）；③Agent 内直接对话「帮我整理 demo-vault 里 408-操作系统的错题并安排复测」。详细见包内 体验说明.md。
