# 演示视频录制操作手册

> 目标：3 分钟 1080p 演示视频 + 2 段 GIF。**分镜录制、剪映拼接**——每个镜头单独录 2~3 遍，不要一镜到底。
> 全程照本手册逐条执行即可，不用即兴发挥。

---

## 第 0 部分：一次性环境准备（约 20 分钟，只做一次）

### 0.1 关闭一切干扰
1. `Win + A` → 打开「勿扰模式」（拦截所有通知弹窗）
2. 关掉卡巴斯基/输入法的浮动提示窗口
3. 关掉所有无关程序（微信、浏览器多余标签）

### 0.2 终端配置（Windows Terminal）
1. 打开 Windows Terminal → `Ctrl + ,` 进设置
2. 默认配置文件选 **命令提示符** 或 **Git Bash**（下文命令两者通用）
3. 外观 → 字号改 **20**，配色方案选 **One Half Dark**（深色）
4. 窗口：启动大小 120 列 × 32 行；显示分辨率保证系统缩放 100%
5. 透明度调 100%（不透明）

### 0.3 录屏工具（二选一）
- **OBS Studio（推荐）**：设置 → 视频 → 基础分辨率 1920×1080、FPS 30；输出 → 录像质量「高质量」、格式 mp4；设置开始/停止录制快捷键（如 `F9`）；来源加「显示器采集」
- **Xbox Game Bar（省事）**：`Win + G` 开启，`Win + Alt + R` 开始/停止，文件落在 `视频\Captures\`

### 0.4 麦克风
1. 用 Windows 录音机试录 10 秒，回放确认没有电流声、背景音小
2. 录制环境：关窗、关风扇；嘴离麦克风一拳

### 0.5 备料窗口（录屏时切过去用）
| 窗口 | 用途 |
| --- | --- |
| 百炼控制台「模型观测/用量统计」页（已登录） | 镜头 6 |
| 本文件 | 逐字稿对照 |
| 仓库 `README.md`（GitHub 网页或 VS Code 预览，渲染出架构图） | 镜头 7 |

### 0.6 录制前状态核验（在仓库根目录 `C:\Users\admin\Desktop\study-copilot-skills` 开一个终端跑）

```
python -m pytest tests/ -q
```
预期末行：`18 passed`。不通过先找我，别带病录制。

### 镜头 4｜Agent 错题闭环 ★（0:55–1:25，最难，放最后录）

- **录屏前**：
  1. 确认已执行过 `python install.py --host claude-code`（正式安装）
  2. 在仓库根目录启动 `claude`（必须在根目录，契约相对路径才能生效）
  3. 准备好输入法一次性打出下面这句话
- **输入（整句发给 Agent）**：
  > 帮我整理 demo-vault 里 408-操作系统 的错题并安排复测
- **预期输出**：Agent 加载 `kaoyan-error-loop-coach`，输出错误簇表格（区分 confirmed/hypothesis）+ ReviewQueue JSON
- **NG 判断**：Agent 没找到错题文件 / 半途问你要权限卡住 / 输出没提 408-操作系统 → 重录
- **口播（画面出来后压着讲）**：
  > 「现在教 Agent 当教练：它按知识点聚类错因，区分已确认和待验证的假设，复测日期写进队列。科目在这里只是个字符串——换法考、换 CPA，机制照跑。」
- **兜底方案**：Agent 表现不稳就放弃实拍，改用提前截好的结果长图，配同一段口播

### 镜头 5｜端侧语义检索 ★核心（1:25–2:00）

- **录屏前**：终端清屏。**先偷偷跑一遍下面第 1 条命令**（热身，让模型加载缓存），再清屏正式录
- **输入（共 2 条）**：
  ```
  python scripts/local_retrieval/embed_index.py
  python scripts/local_retrieval/semantic_search.py --query "进程死锁检测和银行家算法又算错了" --top-k 3
  ```
- **预期输出**：
  - 第 1 条：`已建索引：53 篇文档，维度 512 …耗时 2.3s`（开头可能闪一行英文 ERROR 后自动回退——**正常**，怕丑就热身后清屏再录）
  - 第 2 条：Top-1 应为 `md:30-知识/错题笔记/408-操作系统/死锁簇.md`，分数约 0.78
- **录完补 1 秒**：资源管理器打开 `demo-vault/30-知识/.index/`，展示里面只有本地文件
- **口播**：
  > 「重点来了：端侧。你的电脑本地跑 embedding 模型，给整个错题库建语义索引。打一道新错题，先在本地召回——你是不是老毛病。全程本地 CPU，数据一克都不出门。」

### 镜头 6｜Qwen 真实调用与留痕 ★核心（2:00–2:35）

- **录屏前**：终端清屏；确认已 `setx` 过新 Key 并**新开过终端**（让环境变量生效）
- **输入（共 2 条）**：
  ```
  python scripts/qwen_engine.py --dry-run --system "你是考研408陪练教练" --prompt "围绕错因LRU与FIFO缺页数串页出一道原创变式题"
  python scripts/qwen_engine.py --system "你是考研408陪练教练，只输出原创变式题" --prompt "围绕错因'LRU与FIFO缺页数串页'出一道原创变式选择题并附解析"
  ```
- **预期输出**：
  - 第 1 条秒出请求体 JSON（模型 qwen-flash、log_path_planned）
  - 第 2 条约 20 秒后输出完整变式题——**这 20 秒不要剪掉**：后期 4 倍速 + 角标「真实调用中」，比剪掉更有说服力
- **录完立刻补拍 2 个 2 秒镜头**：
  1. 记事本打开 `logs/qwen/` 里最新 JSON，框选 `usage` 与 `latency_ms` 停 2 秒
  2. 浏览器切到百炼控制台「模型观测/用量统计」，停 2 秒
- **口播**：
  > 「云端交给 Qwen：基于已确认的错因生成原创变式题、二次精讲。每一次调用自动留痕——消息、回复、token 用量、时延，全部落在本地日志里。这就是我们说的：AI 实践，真实可验证。」

## 第 2 部分：剪辑与导出（剪映）

1. **拼装**：新建工程 1920×1080 → 按镜头 1~8 顺序导入素材 → 每段掐头去尾（切掉按快捷键前后的杂乱帧）
2. **镜头 6 处理**：真实调用 20 秒段 → 4 倍速 → 加角标文字「真实调用中 ▶▶▶」
3. **字幕**：文本 → 智能字幕 → 识别字幕 → 逐句校对错别字（专业词：错因、聚类、端侧、留痕）
4. **配乐**：剪映音效库选低音量纯音乐（人声段音乐压到 10%）
5. **导出**：命名 `学习副驾演示视频.mp4`；参数 1080P / 30fps / 推荐码率
6. **GIF 两段**：镜头 5 第二条命令的输出段、镜头 6 留痕文件段，各截 10 秒 → 剪映导出 GIF（720P / 15fps）
