# 演示视频脚本（3 分钟）

> 主打叙事：**同一个学习大脑，装进任何 Agent、任何科目；端侧本地算力 × 云端 Qwen 协同。**
> 录制建议：1920×1080，编辑器 + 终端 + Agent 对话三窗口布局；语速平稳，每镜头按秒数掐。

## 分镜

| # | 时间 | 画面 | 口播/字幕 |
| --- | --- | --- | --- |
| 1 | 0:00–0:15 | 标题卡：学习副驾 Study Copilot；三行大字「任何 Agent / 任何科目 / 端云协同」 | 「AI 学习工具很多，但它们大多绑死一个应用、一个场景。学习副驾把学习大脑做成一套开放 Skills——装进任何 Agent，教任何科目。」 |
| 2 | 0:15–0:35 | 目录树快速滚动：skills/ 15 个 Skill → references/ 22 个契约 → subjects/ 科目包 → demo-vault | 「前身是我们开源的 408 考研插件，这一版做了两层泛化：机制层与宿主解耦，学科内容由科目配置驱动。」 |
| 3 | 0:35–0:55 | 终端：`python install.py --list`；然后 `--host claude-code` 安装；切到 Claude Code 中 Skill 被识别 | 「一条命令，同一套 Skills 装进 Codex 或 Claude Code——注意，没有任何后台服务，全部是本地文件。」 |
| 4 | 0:55–1:25 | Agent 对话：「帮我整理 demo-vault 里 408-操作系统 的错题并安排复测」→ 错题闭环输出：错误簇表格 + ReviewQueue JSON | 「现在教 Agent 当教练：错因聚类区分已确认与假设，间隔复测写进队列。科目只是个字符串——换法考、换 CPA，机制照跑。」 |
| 5 | 1:25–2:00 | 终端：`embed_index.py` 建索引（40 篇错题 + 笔记）；`semantic_search.py --query "死锁检测漏分支"` 输出相似错题 JSON；右上角角标「本地 CPU · 数据不出域」 | 「重点来了：端侧。你的电脑本地跑 embedding 模型，给错题库建语义索引。打一道新错题，先在本地召回‘你是不是老毛病’——数据一克都不出门。」 |
| 6 | 2:00–2:35 | 终端：`qwen_engine.py --dry-run` 预览 → 真实调用 → 输出原创变式题；切到 `logs/qwen/*.json` 留痕文件（usage/时延可见）；再切 DashScope 用量页 | 「云端交给 Qwen：基于错因生成变式复测题、二次精讲。每一次调用自动留痕——这就是我们说的：AI 实践，真实可验证。」 |
| 7 | 2:35–2:50 | 分屏左：`kaoyan-subject-onboarding` 对话「我要加法考科目」生成 subjects/fakao/profile.json；分屏右：架构图（端侧 embedding ↔ 云端 Qwen） | 「新科目？说一句话就生成配置包。端侧管本地语义，云端管推理出题——这就是端云协同。」 |
| 8 | 2:50–3:00 | 结尾卡：仓库名 + 「15 Skills · 2 层泛化 · 端云协同」+ 参赛信息 | 「学习副驾：把学习大脑，装进每一个 Agent。谢谢观看。」 |
