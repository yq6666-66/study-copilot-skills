### 题1（针对错因：安全性检测的序列搜索漏分支）  
**题目**：现有系统中有 4 个进程 $P_1, P_2, P_3, P_4$，可分配资源类型为 $R_1, R_2$，当前可用资源向量为 $(2, 1)$。各进程的最大需求与已分配资源如下：  
- $P_1$: Max = (3,2), Allocation = (1,0)  
- $P_2$: Max = (2,1), Allocation = (1,1)  
- $P_3$: Max = (2,2), Allocation = (0,1)  
- $P_4$: Max = (1,1), Allocation = (1,0)  

请判断当前状态是否安全，并找出一个安全序列。若存在多个安全序列，请说明为何在搜索过程中可能遗漏某一分支。

---

### 题2（针对错因：资源分配图化简的约简顺序遗漏）  
**题目**：某系统中存在 3 个进程 $P_1, P_2, P_3$ 与 2 种资源 $R_a, R_b$，资源总数分别为 3 和 2。当前资源分配与请求情况如下：  
- $P_1$ 已占 $R_a:1$, $R_b:1$，请求 $R_a:1$  
- $P_2$ 已占 $R_a:1$, $R_b:0$，请求 $R_b:1$  
- $P_3$ 已占 $R_a:0$, $R_b:1$，请求 $R_a:1$  

系统当前可用资源为 $R_a:1$, $R_b:1$。请绘制资源分配图并进行化简。指出在约简过程中，若未尝试所有可能的可约简进程顺序，可能导致误判死锁状态的原因。

---

### 题3（针对错因：P/V 操作顺序颠倒导致死锁）  
**题目**：两个进程 $P_1$ 与 $P_2$ 共享一个缓冲区，使用信号量机制实现同步。初始时，`empty = 1`, `full = 0`，互斥信号量 `mutex = 1`。  
- $P_1$（生产者）执行：  
  ```c
  P(mutex);
  produce_item();
  V(mutex);
  P(empty);
  V(full);
  ```
- $P_2$（消费者）执行：  
  ```c
  P(full);
  P(mutex);
  consume_item();
  V(mutex);
  V(empty);
  ```

分析该代码是否存在死锁风险？若存在，请指出是由于哪一步的 P/V 操作顺序错误所导致，并说明正确的顺序应如何调整。
```
