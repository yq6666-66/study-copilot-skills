# 端侧语义检索契约

学习 Skill 可在**用户本地 AI PC**上运行向量语义检索，为错题闭环与真题登记提供相似历史依据。检索与云端大模型形成端云分工：**端侧负责本地语料的相似召回，云端负责推理与讲解**。

## 何时使用

- `kaoyan-error-loop-coach`：聚类错因前，检索与当前错题语义相似的历史错题与笔记，辅助判断"是否老毛病"。
- `kaoyan-past-paper-searcher`：登记真题来源前，检索已有条目避免重复登记。
- 其他 Skill 需要跨会话语料召回时，可作为学习层辅助，但不改变各自主责。

## 调用方式

1. 首次使用先建索引（语料变化后重建）：

   ```bash
   python scripts/local_retrieval/embed_index.py --corpus <Vault根目录>
   ```

2. 会话内检索：

   ```bash
   python scripts/local_retrieval/semantic_search.py --query "<查询句>" --top-k 5 [--subject <科目>]
   ```

3. 模型未就绪时先运行 `python scripts/local_retrieval/download_model.py`（约 100MB，缓存到仓库 `models/`）。

## 结果标注

检索结果**不是**当前官方事实或真题来源证明。实际使用的检索内容在回答中标注 `[端侧检索]` 并附来源路径（与 `[Obsidian记忆]` 同级，不混用）。

## 隐私与边界

- 全部计算在本地完成，索引存于本地 `.index/` 目录；除模型首次下载外无网络流量。
- 不上传笔记、错题或个人数据；云端调用（如 Qwen 陪练）只发送学科文本，与本契约互不越界。
- 不得将整篇笔记正文原样注入上下文，只引用检索片段。

## 降级规则

- 依赖缺失 / 模型未下载 / 索引不存在时，**不阻塞学习回答**，按未连接口径提示：
  - `端侧检索：未就绪（原因）；本轮使用会话信息与 Obsidian 记忆。`
- 用户说「只读模式」或「本次不检索」时跳过端侧检索，直接回答。
- 索引过期（语料修改时间晚于 `meta.json` 的 `built_at`）时提示重建，不自动重写用户目录。
