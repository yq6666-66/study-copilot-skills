# 云端引擎契约

云端大模型（任意 OpenAI 兼容接口）是学习副驾的云端推理通道之一，**默认只承担「错题陪练」链路**：基于错题簇生成变式复测题与二次精讲。其余常规推理由宿主 Agent 自身模型完成，不得把全部对话转发给云端。

## 使用边界

- 主责 Skill：`kaoyan-qwen-drill`。其他 Skill 需要时经交接卡转交，不越界。
- 出题与讲解内容标 `[原创练习][AI生成]` / `[AI生成]`，不与 `[用户材料]`、`[Obsidian记忆]`、`[端侧检索]` 混用。

## 调用纪律

1. 一律通过 `scripts/qwen_engine.py` 调用；先 `--dry-run` 预览请求体，确认无个人信息后再真实调用。
2. **留痕是硬要求**：每次真实调用自动写 `logs/qwen/<时间戳>-<模型>.json`（消息、回复、token 用量、时延）。Skill 在产出中附日志路径。
3. 服务商与模型由环境变量决定：`OPENAI_BASE_URL` / `OPENAI_MODEL` / `OPENAI_API_KEY`（兼容 `LLM_*`、`DASHSCOPE_API_KEY` 历史变量）。控制 token 用量，单次请求聚焦一个错题簇。

## 隐私边界

- 只发送**学科内容文本**：题目知识点、错因描述、要求产出格式。
- 不发送：用户身份信息、笔记全文、路径中的用户名、任何凭据。
- 日志不落盘 API Key（引擎内置断言）；日志在本地 `logs/qwen/`，用户可随时删除。

## 降级规则

- 未配置密钥、调用失败或超时：**不阻塞学习回答**，降级为会话内出题并明示「本次未使用云端模型」。
- 不得为了演示伪造云端输出；没有真实调用就没有 `[AI生成]` 标注。
